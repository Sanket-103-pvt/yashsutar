# Yash Sutar Portfolio

Single-page portfolio for Yash Praveen Sutar, mechanical design engineer from Nashik.

- `index.html` holds all markup, styles and scripts.
- `assets/yash.jpg` is the portrait used in the hero.
- Fonts load from Google Fonts. No build step.

Open `index.html` in a browser, or enable GitHub Pages on the `main` branch (root folder) to host it.
